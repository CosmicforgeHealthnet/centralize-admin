# Advertising Execution metrics and health

Structured event names are exactly: `marketing_execution.plan_validated`, `.approval_recorded`, `.job_claimed`, `.operation_started`, `.operation_succeeded`, `.operation_failed`, `.operation_unknown`, `.reconciliation_drift`, `.compensation_queued`, `.kill_switch_changed`.

Production emitters are the validation/approval services, queue service, worker, operation runner, reconciliation service and kill-switch service. The shared event adapter sanitizes and bounds payloads before structured logging, realtime delivery and reuse of the existing Admin notification service. Request correlation IDs flow from the shared request-context middleware into success/error envelopes, audits and events.

The bounded metrics adapter covers plan/validation/submission/cancellation, approval latency and outcomes, job state/age/lease/heartbeat/contention, operation outcomes/attempts/retries/preconditions/latency, provider read/write/rate-limit/permission/capability, targeting cache/discovery, review status, Decimal-safe budget exposure, reconciliation state/latency/incident age and compensation lifecycle. Only provider, operationType, resourceType, resultCategory, status, bounded API version, workerType and currency may be labels. Plan/run/account/provider-request identifiers are rejected as labels.

Authenticated `GET /health` reports `ready`, `degraded`, `disabled` or `unavailable`, plus master/dry-run/worker registration and running state, queue depth/age, reconciliation depth/age, configured provider/API-version blockers, cached full-schema readiness (25 tables, 20 indexes and 7 enums), and functional audit/metrics/notification/realtime method readiness. Optional provider/connection context reports only sanitized connection presence, credential-present, read/write gate, capability freshness and bounded failure category; it never promotes one account to global provider readiness. Disabled-by-configuration is safe; missing database schema is unavailable. Tokens, credential envelopes, native bodies, account secrets, lease/lock owners, signed URLs and stack traces are recursively removed.
